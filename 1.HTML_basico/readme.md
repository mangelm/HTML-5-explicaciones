# 🧱 HTML básico

### Los primeros pasos para construir una página web

Explora la estructura de un documento HTML, practica con elementos y atributos, y aprende a encontrar errores.

</div>

---

## 🗺️ Recorrido recomendado

### 1. Construye una página

En [📄 Plan de estudios](1.Proyecto_Plan_De_Estudios/plan_de_estudios.html) encontrarás una página con títulos y párrafos. Fíjate en cómo se organiza el contenido y en la jerarquía de encabezados.

### 2. Explora elementos y atributos

- [📄 Atributos](3.Atributos/atributos.html): encabezados, párrafos e imágenes; observa atributos como `src` y `alt`.
- [📄 Más atributos](3.Atributos/atributos_2.html): enlaces con `href` y `target`, imágenes, campos de entrada y atributos booleanos como `checked` y `disabled`.
- [📄`div` y `section`](7.Fundamentos_HTML/div.html): compara cómo agrupar elementos con `<div>`, sin significado semántico propio, y con `<section>`, para contenido relacionado.
- [🖼️ Imagen de ejemplo](imagenes/cats.jpg): recurso local usado en algunos ejemplos.

### 3. Construye el proyecto de fotos de gatos

Este proyecto está dividido en tres pasos para mostrar cómo va creciendo la página. El archivo **final** es el proyecto completo; puedes abrirlo directamente o recorrer los pasos para ver cómo se construyó.

| Paso | Archivo | Qué incorpora |
|---|---|---|
| 1 | [imagenes_gatos.html](5.Proyecto_aplicacion_imagenes_gatos/imagenes_gatos.html) | Encabezados, enlaces e imágenes de gatos. |
| 2 | [imagenes_gatos_2.html](5.Proyecto_aplicacion_imagenes_gatos/imagenes_gatos_2.html) | Imagen enlazada y primera lista de cosas que les gustan a los gatos. |
| ⭐ **Proyecto completo** | [**imagenes_gatos_final.html**](5.Proyecto_aplicacion_imagenes_gatos/imagenes_gatos_final.html) | Versión final con listas, imágenes con `figure` y `figcaption`, texto destacado y pie de página. |

### 4. Practica con una receta

En este ejercicio crearás una página para una receta de galletas con chispas de chocolate. Practicarás encabezados, párrafos, listas de ingredientes e instrucciones, además de añadir una imagen con texto alternativo.

- [✍️ Ejercicio: crea la página de la receta](6.Proyecto_Receta/receta.html)
- [✅ Solución completa](6.Proyecto_Receta/receta_solucion.html)
- [🖼️ Imagen de la receta](imagenes/recipe.jpg)

Intenta completar el ejercicio antes de consultar la solución.

### 5. Revisa la plantilla y la codificación

- [📄 Plantilla HTML](4.Plantilla_html/plantilla.html): estructura básica de un documento HTML.
- [📄 Explicación de la plantilla](4.Plantilla_html/explicacion_plantilla.html): función de las etiquetas y metadatos principales.
- [📄 Codificación UTF-8](4.Plantilla_html/codificacion_utf8.html): ejemplos de acentos y caracteres especiales en el documento.

### 6. Encuentra y corrige errores

En [📂 Depurar (debug)](2.Depurar(debug)) hay dos ejercicios. Intenta resolverlos antes de abrir las soluciones.

| Ejercicio | Practica | Solución |
|---|---|---|
| [Ejercicio 1](2.Depurar(debug)/ejercicio_01.html) | Etiquetas `h1`, `h2`, `h3` y `p`; cierres correctos. | [Ver solución](2.Depurar(debug)/ejercicio_01_solucion.html) |
| [Ejercicio 2](2.Depurar(debug)/ejercicio_02.html) | Imágenes y enlaces: `src`, `alt` y `href`. | [Ver solución](2.Depurar(debug)/ejercicio_02_solucion.html) |

## ✅ Cómo aprovechar los ejercicios

1. Lee el enunciado y las pistas del archivo.
2. Intenta resolverlo por tu cuenta.
3. Abre la página en un navegador para comprobar el resultado.
4. Cuando termines, compara tu trabajo con la solución.
